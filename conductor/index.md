## 🚀 Быстрый старт

### Требования
- Python 3.11+
- Windows/Linux (основная разработка под Windows)
- GPU с CUDA 11.8+ (рекомендуется для детекции)
- MaixCAM (для работы с реальным оборудованием)

### Установка
```bash
# Клонировать репозиторий
git clone <repository-url>
cd drone_trainer

# Создать виртуальное окружение
python -m venv venv
source venv/bin/activate  # Linux
venv\Scripts\activate     # Windows

# Установить зависимости
pip install -r requirements.txt

# Запустить приложение
python main.py
```
