# Initial Concept

## Оптико-электронный интерактивный тренажёр для отработки стрельбы по БПЛА

### Описание
Создание интерактивного программно-аппаратного тренажёра для отработки навыков наведения и поражения беспилотных летательных аппаратов (БПЛА) с автоматической фиксацией и оценкой результатов стрельбы.

### Команда
- **Создатели:** курсанты 631/12 уч. гр. — Хазиев Г.Р., Скрыпник Е.М., Гусев А.Д.
- **Научный руководитель:** полк. Карпов В.Б. (102 кафедра)

### Целевые пользователи
- Стрелки, отрабатывающие навыки поражения малоразмерных высокоманёвренных воздушных целей
- Тренеры/руководители занятий, контролирующие процесс и результаты

### Ключевые функции
- Захват видеопотока с оптико-электронного блока (MaixCAM) на ПК
- Детекция и сегментация БПЛА с использованием YOLOv8s-seg
- Автоматическая оценка попадания (прицел внутри маски дрона)
- Калибровка прицела (имитация выстрела → отметка точки прицеливания)
- Расчёт упреждения на больших дистанциях
- Ведение журнала тренировок со статистикой

### Архитектура (обсуждённая)
- **Гибридная передача данных:** поток видео (MJPEG) для визуализации + single-frame по триггеру для точного анализа
- **Детекция на ПК** (YOLOv8s-seg) — максимальная точность
- **GUI для тренера** на PyQt6
- **Связь:** UDP между MaixCAM и ПК

# Product Guide

## Vision Statement

Интерактивный оптико-электронный тренажёр для подготовки стрелков к поражению БПЛА — программно-аппаратный комплекс с автоматической оценкой результатов на базе компьютерного зрения.

## Problem Statement

Традиционные методы огневой подготовки по БПЛА:
- Высокая стоимость боеприпасов и организации занятий
- Повышенные требования к безопасности
- Отсутствие объективной автоматизированной оценки результатов
- Невозможность безопасной отработки навыков наведения по малоразмерным манёвренным целям

## Solution

Программно-аппаратный комплекс, состоящий из:
1. **Оптико-электронного блока** (MaixCAM + камера + триггер + АКБ 1800 мА·ч) — устанавливается на макет стрелкового оружия
2. **ПК оператора** с GUI для тренера/руководителя занятий

## Target Users

1. **Стрелки** — курсанты/военнослужащие, отрабатывающие навыки наведения и поражения БПЛА из стрелкового оружия
2. **Тренеры/руководители занятий** — контролируют процесс, калибруют прицел, анализируют статистику

## Key Features

1. **Видеопоток в реальном времени** — тренер видит ситуацию "как стрелок" (5-10 FPS MJPEG)
2. **Детекция и сегментация БПЛА** (YOLOv8s-seg) — точный контур цели на ПК
3. **Калибровка прицела** — предварительная имитация выстрела → отметка точки прицеливания на кадре
4. **Автоматическая оценка попадания** — прицел внутри маски/контура дрона
5. **Функция упреждения** — расчёт упреждения для стрельбы на больших дистанциях по движущимся целям
6. **Журнал тренировок** — статистика попаданий/промахов, время реакции, координаты, скриншоты
7. **Автономная работа** — без специализированной инфраструктуры, развёртывание ≤5 минут

## Architecture

**Гибридная передача данных (обсуждённая):**
- **Видеопоток (MJPEG)** — визуализация для тренера в реальном времени (низкая нагрузка на сеть)
- **Single-frame по триггеру** — full-resolution JPEG для точного анализа попадания
- **Разделение портов:** видео (5000) + результаты (5001)

**Детекция на ПК** — максимальная точность (FP32, YOLOv8s-seg, высокое разрешение, SAHI)

**Модули:**
- Оптико-электронный блок (MaixCAM, триггер, АКБ)
- Тактический модуль (Wi-Fi роутер, AP/STA, UDP)
- Вычислительный модуль (ПК, YOLOv8s-seg)
- GUI тренера (PyQt6)

## Success Criteria

- Распознавание БПЛА на дистанции 70–100 м
- Задержка результата ≤20 мс (от триггера до отображения попадания)
- Развёртывание комплекса ≤5 минут
- Точность оценки попадания >90%
- Работа на ПК: Intel Core i5 / AMD Ryzen 5, 8 ГБ RAM, Windows

## Non-functional Requirements

- Автономное питание (АКБ 1800 мА·ч, ~2-3 часа работы)
- Совместимость с ОС Windows
- Модульная конструкция (лёгкая замена компонентов)
- Высокая скорость развёртывания и подготовки к применению
- Возможность отработки действий как стрелка, так и оператора БПЛА
- Работа без специализированной инфраструктуры

## Constraints

- Ограниченная вычислительная мощность MaixCAM (NPU ~1 TOPS)
- Зависимость качества детекции от освещения и разрешения камеры
- Беспроводная связь (Wi-Fi) — чувствительность к помехам
- Необходимость обучения модели на специализированном датасете (VisDrone, UAVDT)
