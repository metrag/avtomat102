# Tech Stack

## Programming Language

**Python 3.11+**

- **Обоснование:** Богатая экосистема для компьютерного зрения (OpenCV, Ultralytics), быстрая разработка прототипов, кроссплатформенность
- **Альтернативы:** C++ (выше производительность, но сложнее разработка), Rust (безопасность, но незрелая экосистема для CV)
- **Требования:** Python 3.11 или выше для поддержки последних версий Ultralytics YOLOv8

## GUI Framework

**PyQt6 (PySide6)**

- **Обоснование:** Зрелый, мощный фреймворк с богатой документацией, поддержка сигналов/слотов для асинхронной обработки видео, нативный виджет для отображения видео (QLabel/QGraphicsView)
- **Альтернативы:** Tkinter (проще, но менее гибкий), ImGui (быстрее, но менее нативный вид), wxPython (кроссплатформенный, но менее популярный)
- **Версия:** PyQt6 6.5+ или PySide6 6.5+
- **Дополнительно:** PyQt6-Charts для графиков статистики (опционально)

## Computer Vision & Machine Learning

### Детекция и сегментация
**Ultralytics YOLOv8 (YOLOv8s-seg)**

- **Модель:** YOLOv8s-seg (small segmentation) — баланс скорости и точности
- **Обоснование:** Современная архитектура, отличная точность на малоразмерных объектах, поддержка сегментации из коробки, активное сообщество
- **Альтернативы:** YOLOv5-seg (стабильнее, но менее точная), YOLOX (anchor-free, но сложнее настройка), RT-DETR (transformer-based, но тяжелее)
- **Версия:** Ultralytics 8.1+
- **Требования:** PyTorch 2.0+, CUDA 11.8+ (для GPU-ускорения)

### Предобработка изображений
**OpenCV (cv2)**

- **Обоснование:** Стандарт индустрии, быстрая обработка изображений, декодирование MJPEG/JPEG, геометрические трансформации
- **Версия:** OpenCV 4.8+
- **Дополнительно:** opencv-contrib-python для расширенных функций

### Дополнительные библиотеки
**NumPy**

- **Обоснование:** Матричные операции для расчёта упреждения, обработка массивов координат
- **Версия:** NumPy 1.24+

## Networking

### UDP Communication
**Python socket (встроенный)**

- **Обоснование:** Низкая задержка (не требуется подтверждение доставки), простота реализации, подходит для потокового видео
- **Архитектура:**
  - Видеопоток: порт 5000 (MJPEG, 5-10 FPS)
  - Триггерные кадры: порт 5001 (full-res JPEG)
  - Результаты: порт 5002 (JSON с координатами, ID, временем)
- **Альтернативы:** asyncio (сложнее, но лучше для высокой нагрузки), ZeroMQ (надёжнее, но тяжелее)
- **Формат данных:** JSON для метаданных, binary для изображений

### Протокол передачи
**MJPEG + JPEG**

- **Видеопоток:** MJPEG (Motion JPEG) — каждый кадр как отдельный JPEG, простая декодировка
- **Триггерные кадры:** JPEG (quality 95%) — максимальное качество для точной детекции
- **Альтернативы:** H.264 (выше сжатие, но сложнее декодировка), WebP (лучше сжатие, но медленнее)

## Data Storage

### Локальное хранение
**SQLite**

- **Обоснование:** Лёгкая встроенная БД, не требует отдельного сервера, подходит для журнала тренировок
- **Версия:** SQLite 3.35+
- **Структура:**
  - Таблица `sessions`: ID, дата, время, количество выстрелов, процент попаданий
  - Таблица `shots`: ID сессии, номер выстрела, время, результат (попадание/промах), координаты (x, y), скриншот (путь к файлу)
  - Таблица `calibration`: ID, смещение прицела (offset_x, offset_y), дата
- **Альтернативы:** JSON files (проще, но сложнее запросы), PostgreSQL (мощнее, но избыточно для локального хранения)

### Файловое хранилище
**Локальная файловая система**

- **Скриншоты:** `data/screenshots/{session_id}/{shot_number}.jpg`
- **Экспорт статистики:** `data/exports/{date}_report.csv`
- **Конфигурация:** `config/settings.json` (настройки упреждения, калибровки, порогов детекции)

## Image Processing Pipeline

### Декодирование
**OpenCV + PIL (Pillow)**

- **OpenCV:** Декодирование MJPEG потока, преобразование цветовых пространств (BGR ↔ RGB)
- **Pillow:** Сохранение скриншотов высокого качества, ресайзинг для журнала
- **Версия:** Pillow 10.0+

### Аннотации
**OpenCV (cv2)**

- **Рисование контуров:** cv2.drawContours() для масок сегментации
- **Текст:** cv2.putText() для отображения координат, статистики
- **Геометрия:** cv2.circle(), cv2.rectangle(), cv2.line() для прицела, bbox, векторов упреждения

## Development Tools

### Менеджер зависимостей
**pip + requirements.txt**

- **Обоснование:** Стандартный инструмент Python, простота использования, совместимость с CI/CD
- **Альтернативы:** Poetry (лучше управление версиями, но сложнее), pipenv (зрелый, но медленнее)

### Виртуальное окружение
**venv (встроенный)**

- **Обоснование:** Простота, не требует установки дополнительных инструментов
- **Команда создания:** `python -m venv .venv`
- **Альтернативы:** conda (лучше для научных библиотек, но тяжелее), virtualenv (быстрее, но требует установки)

### Линтинг и форматирование
**Ruff**

- **Обоснование:** Быстрый линтер и форматтер (замена flake8 + black + isort), написан на Rust
- **Конфигурация:** `pyproject.toml` или `ruff.toml`
- **Альтернативы:** black + flake8 + isort (классика, но медленнее), pylint (строже, но медленнее)

### Тестирование
**pytest**

- **Обоснование:** Мощный фреймворк для unit/integration тестов, богатая экосистема плагинов
- **Версия:** pytest 7.4+
- **Дополнительно:** pytest-cov для покрытия кода, pytest-qt для тестирования GUI
- **Покрытие:** ≥80% (согласно workflow)

## Deployment

### Упаковка
**PyInstaller**

- **Обоснование:** Создание standalone .exe для Windows, не требует установки Python на целевой машине
- **Команда:** `pyinstaller --onefile --windowed main.py`
- **Альтернативы:** cx_Freeze (стабильнее, но сложнее настройка), Nuitka (быстрее, но менее зрелый)

### Установка
**Inno Setup**

- **Обоснование:** Бесплатный установщик для Windows, простой скриптовый язык, поддержка ярлыков и меню Пуск
- **Альтернативы:** NSIS (более гибкий, но сложнее), WiX (мощнее, но требует XML)

## Hardware Integration

### MaixCAM
**MaixPy (MaixCDK)**

- **Обоснование:** Официальный SDK для MaixCAM, поддержка NPU, камера, GPIO
- **Версия:** MaixPy 4.x
- **Функции:** Захват видео, обработка триггера, передача по Wi-Fi

### GPIO (опционально)
**RPi.GPIO или gpiod**

- **Обоснование:** Если используется Raspberry Pi для эмуляции триггера (на этапе разработки без MaixCAM)
- **Альтернативы:** pigpio (быстрее, но требует демона)
