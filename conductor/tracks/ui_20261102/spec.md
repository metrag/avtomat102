# Спецификация: Проработка интерфейса и стиля (UI/UX)

## Обзор

Доработка главного окна GUI тренера: компоновка, тёмная тема в стиле product-guidelines, иконки/индикация, экран статистики. Без изменения логики детекции/сети.

## Функциональные требования

1. **Раскладка**: видео слева (крупно, сохранение пропорий 4:3), справа колонка ~360px (панель управления F1/F2/F3 + статистика), журнал выстрелов во всю ширину снизу
2. **QSS-стилизация**: единый `src/gui/styles.qss` — фон #1E1E1E, акцент #00FF41, шрифты/отступы/кнопки (normal/hover/pressed), тёмные скроллбары/таблицы; применение при старте
3. **Иконки и индикация**: иконки кнопкам F1/F2/F3, статус-индикатор сессии (активна/неактивна), подсветка строк журнала (попадание — зелёная, промах — красная)
4. **Экран статистики**: отдельный диалог/вкладка — сводка сессии (попаданий/промахов, точность %, среднее время между выстрелами), источник — SQLite-журнал
5. **Окно**: по умолчанию 1440×900, минимальный ~1024×700, корректный ресайз (видео не ломается)

## Критерии приёмки

- pytest (16 тестов) остаётся зелёным; чистая логика статистики покрыта новыми тестами
- Окно соответствует раскладке 1; QSS применяется из одного источника
- Строки журнала окрашиваются; экран статистики открывается и считает из journal.db
- Ручная проверка: `.venv\Scripts\python.exe main.py` — окно выглядит по описанию

## Вне scope

Детекция, сеть, код MaixCAM, новые функции занятий
