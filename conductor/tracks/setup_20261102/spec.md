# Спецификация: Заставка, форма настройки и правки интерфейса

## Обзор

Стартовое окно приложения (заставка → форма настройки занятия), правки калибровки и журнала, сохранение фото и результатов сессии.

## Функциональные требования

1. **Заставка**: при запуске — первое окно с названием/командой проекта, кнопка «Далее» → форма настройки
2. **Форма настройки занятия**: звание (QComboBox: Курсант, Мл. сержант, Сержант, Ст. сержант, Прапорщик, Лейтенант), ФИО, № учебной группы, режим стрельбы (Автоматический = детекция засчитывает / Ручной = тренер отмечает попадание/промах), дистанция (пресеты 50/70/100/150/200 м + «Своя» → число), кол-во патронов (SpinBox). Кнопка «Начать» → главное окно, данные видны в заголовке/панели
3. **Калибровка**: исправить серые рамки в CalibrationDialog — чистый вид по QSS, понятная подсказка, кнопка «Готов»
4. **Журнал**: убрать колонку «Координаты» → 3 колонки (№, Время, Результат)
5. **Фото выстрелов**: каждый выстрел → кадр в `data/shots/<session_id>/<N>.jpg`, путь в таблицу shots; двойной клик по строке журнала — просмотр фото (заглушка-плейсхолдер, если кадра ещё нет)
6. **Результаты сессии**: в sessions добавить звание, ФИО, группу, режим, дистанцию, патроны (миграция SQLite при старте) — история сохраняется

## Критерии приёмки

- pytest зелёный (старые 25 + новые на миграцию/фото-логику)
- Запуск: заставка → форма → главное окно
- В журнале 3 колонки; выстрел создаёт jpg + запись в БД
- Калибровка без серых рамок

## Вне scope

Детекция, сеть, код MaixCAM

## Примечание исполнителю

Реализация выполняется текущей моделью напрямую, без делегирования субагенту.
