# Product Guidelines

## Tone of Voice

**Формальный, технический, уверенный**

- Используйте профессиональную терминологию (тактико-технические характеристики, алгоритмы детекции, сегментация)
- Избегайте разговорных выражений и сленга
- Чёткие, лаконичные формулировки без двусмысленности
- Фокус на точности и надёжности информации
- Пример: "Система выполняет детекцию БПЛА с точностью 95% на дистанции 70-100 м" вместо "Прога неплохо находит дроны"

## Visual Style

### Цветовая палитра
- **Основной фон:** Тёмно-серый (#1E1E1E) или чёрный (#000000) — снижает нагрузку на глаза при длительной работе
- **Акцентный цвет:** Тактический зелёный (#00FF41) или оранжевый (#FF6600) — для важных элементов управления и индикаторов
- **Текст:** Белый (#FFFFFF) или светло-серый (#CCCCCC) — высокий контраст для читаемости
- **Семантические цвета:**
  - Успех (попадание): Зелёный (#00FF00)
  - Ошибка (промах): Красный (#FF0000)
  - Предупреждение: Жёлтый (#FFFF00)

### Типографика
- **Основной шрифт:** Monospace (Consolas, Monaco, или Courier New) — для технических данных и координат
- **UI элементы:** Sans-serif (Segoe UI, Arial) — для кнопок и меню
- **Размеры:**
  - Заголовки: 18-24px (bold)
  - Основной текст: 14-16px
  - Технические данные: 12-14px (monospace)

### Иконки
- Минималистичные, линейные иконки (thickness 2px)
- Размер: 24x24px для кнопок, 16x16px для индикаторов
- Контрастные, различимые при плохом освещении

## UX Principles

### 1. Функциональность превыше всего
- Каждый элемент интерфейса должен иметь чёткую purpose
- Избегайте декоративных элементов, не несущих функциональной нагрузки
- Приоритет: скорость доступа к ключевым функциям (калибровка, ступ занятия, анализ результатов)

### 2. Минимальное количество кликов
- Критические действия (старт/стоп занятия, калибровка) — не более 1-2 кликов
- Используйте горячие клавиши для частых операций:
  - `F1` — Калибровка прицела
  - `F2` — Начать занятие
  - `F3` — Завершить занятие
  - `Esc` — Отмена текущего действия

### 3. Обратная связь в реальном времени
- Все действия пользователя должны получать немедленную визуальную обратную связь
- Индикаторы состояния системы (подключение к MaixCAM, обработка кадра, детекция)
- Прогресс-бары для длительных операций (загрузка модели, сохранение журнала)

### 4. Работа в полевых условиях
- Высокий контраст для читаемости при ярком освещении
- Крупные элементы управления (минимум 44x44px) — работа в перчатках
- Минимум модальных окон — прерывание рабочего процесса недопустимо
- Возможность работы без мыши (полная клавиатурная навигация)

### 5. Надёжность и отказоустойчивость
- Автоматическое сохранение состояния при потере связи
- Локальное кэширование данных при обрыве UDP-соединения
- Чёткие сообщения об ошибках с указанием действий по устранению
- Возможность продолжения работы после восстановления связи

## Accessibility

- **Контрастность:** Минимум 7:1 для текста (WCAG AAA)
- **Размер элементов:** Все интерактивные элементы ≥ 44x44px
- **Клавиатурная навигация:** Полная поддержка Tab/Enter/Esc
- **Цветовая слепота:** Не полагайтесь только на цвет для передачи информации (используйте иконки + текст)
- **Масштабирование:** Поддержка масштабирования интерфейса до 150%

## Performance

- **Время отклика UI:** ≤ 100 мс для любых действий пользователя
- **Загрузка приложения:** ≤ 5 секунд до готовности к работе
- **Потребление RAM:** ≤ 2 ГБ для GUI-приложения
- **FPS видеопотока:** Стабильные 5-10 FPS без просадок
- **Обработка кадра:** ≤ 200 мс от получения до отображения результата детекции

## Security

- **Локальное хранение данных:** Все данные тренировок хранятся локально на ПК
- **Шифрование связи:** WPA3 для Wi-Fi соединения между MaixCAM и ПК
- **Аутентификация:** Нет (автономная система, не требует входа)
- **Целостность данных:** Проверка контрольных сумм для критичных пакетов (результаты стрельбы)
- **Защита от несанкционированного доступа:** Блокировка интерфейса по тайм-ауту (настраивается, по умолчанию 15 минут)

## Documentation Style

- **Технические документы:** Формальный стиль, структурированные разделы, нумерованные списки
- **Пользовательское руководство:** Пошаговые инструкции с скриншотами, нумерованные шаги
- **Сообщения об ошибках:** Формат: [Код ошибки] Краткое описание → Действие по устранению
  - Пример: `[ERR_001] Потеря связи с MaixCAM → Проверьте подключение Wi-Fi и убедитесь, что устройство включено`

## Localization

- **Язык интерфейса:** Русский (основной)
- **Поддержка других языков:** Не требуется в текущей версии
- **Форматы:**
  - Дата: ДД.ММ.ГГГГ
  - Время: ЧЧ:ММ:СС (24-часовой формат)
  - Расстояние: метры (м)
  - Скорость: м/с
