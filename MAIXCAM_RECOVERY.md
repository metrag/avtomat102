# Инструкция по восстановлению MaixCAM

## Текущая ситуация

MaixCAM завис после запуска `video_stream.py` с ошибкой:
```
No buffer space available
```

**Симптомы:**
- ✓ Ping работает (TTL=64, <1мс) - устройство в сети
- ✗ SSH недоступен (Error reading SSH protocol banner)
- ✗ TCP control server (порт 5005) не отвечает

**Причина:** Скрипт пытался инициализировать камеру, но не смог выделить DMA-буферы из-за нехватки памяти или ресурсов.

## Что нужно сделать

### Шаг 1: Физическая перезагрузка

1. **Отключите питание MaixCAM** (отсоедините USB кабель)
2. **Подождите 5 секунд**
3. **Подключите USB кабель обратно**
4. **Подождите ~30 секунд** для полной загрузки системы

### Шаг 2: Проверка доступности

После перезагрузки проверьте:

```powershell
# Проверка ping
ping 10.1.222.1 -n 3

# Ожидание: Ответы с TTL=64, время <1мс
```

### Шаг 3: Деплой улучшенной версии

Запустите скрипт деплоя:

```powershell
.venv\Scripts\python.exe maixcam/deploy_v2.py
```

Этот скрипт:
- ✓ Проверит подключение к control server
- ✓ Остановит текущий скрипт (если есть)
- ✓ Загрузит `video_stream_v2.py`
- ✓ Запустит скрипт
- ✓ Проверит логи

### Шаг 4: Запуск UDP приёмника

В отдельном терминале запустите приёмник видео:

```powershell
.venv\Scripts\python.exe maixcam/test_udp_receiver.py
```

Ожидание: Должны появляться строки с номерами кадров и FPS.

## Что улучшено в video_stream_v2.py

1. **Обработка ошибок инициализации камеры**
   - Проверка возврата `None` от `cam.read()`
   - Автоматический переход в тестовый режим при недоступности камеры

2. **Счётчик ошибок**
   - Автоматическая остановка после 10 последовательных ошибок
   - Предотвращение зависания системы

3. **Освобождение ресурсов**
   - Корректное освобождение камеры при завершении
   - Блок `finally` для гарантированной очистки

4. **Подробное логирование**
   - Все сообщения с `flush=True` для немедленного вывода
   - Информация о размере кадров и FPS

## Диагностика

Если после деплоя видео не работает:

## Возможные проблемы

### Проблема: Control server не запускается

**Решение:** Проверьте, что `/etc/rc.local` содержит:
```bash
nohup python3 /root/control_server.py > /tmp/control_server.log 2>&1 &
```

### Проблема: Ошибка "No buffer space available" повторяется

**Причина:** Нехватка DMA-буферов для камеры.

**Решения:**
1. Уменьшить разрешение камеры в `video_stream_v2.py`:
   ```python
   RESOLUTION = (320, 240)  # вместо (640, 480)
   ```

2. Уменьшить качество JPEG:
   ```python
   JPEG_QUALITY = 50  # вместо 70
   ```

3. Увеличить интервал между кадрами:
   ```python
   FRAME_INTERVAL = 0.2  # 5 FPS вместо 10 FPS
   ```

### Проблема: SSH всё ещё недоступен

**Решение:** Проверьте, что `/etc/rc.local` не содержит конфликтующих скриптов. Очистите его:
```bash
#!/bin/sh
# Пустой файл или только наши команды
```

## Контакты для отладки

Если проблемы сохраняются, проверьте:
1. Логи MaixCAM: `/tmp/maixcam_script.log`
2. Логи control server: `/tmp/maixcam_control.log`
3. Состояние памяти: `free -h`
4. Список процессов: `ps aux`
